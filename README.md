cat-voicemail writes one line to a text file: the voicemail greeting a cat recorded for its human's phone. The line was picked from 37 candidates by pairwise judging against the brief — it has to read as a cat's voicemail, the joke has to come from something specific to cats, and the cat has to sound like a character with an attitude of its own. This cat knocked the phone off the bed and blames the phone for looking at it wrong. The grudge is the joke: the phone gets no apology, only an instruction to leave a message after the beep.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 117 characters, a single line, and ends on the beep so it works as a greeting. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
